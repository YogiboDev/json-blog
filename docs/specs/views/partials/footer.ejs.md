## 1. 概要

| 項目 | 内容 |
|---|---|
| ファイルパス | `views/partials/footer.ejs` |
| 役割 | 全画面共通のHTML末尾部（`<main>`終了タグ〜フッター〜`</body></html>`）を提供する共通パーツ |
| インクルード元 | `index.ejs`, `post.ejs`, `new-post.ejs`, `calendar.ejs`, `404.ejs`（各テンプレート末尾で`<%- include('partials/footer') %>`により読み込み） |

## 2. 位置づけ・依存関係

- `header.ejs`が開いた`<main class="container">`をこのファイルで閉じる。両ファイルは常にペアで使用する。

## 3. 詳細仕様

### 3.1 受け取る変数

なし（固定文言のみのため、外部からの変数受け渡しは不要）

### 3.2 描画内容

1. `</main>`
2. `<footer class="site-footer">`：固定文言「JSON Blog — JSONファイルベースのシンプルなブログシステム」
3. `</body></html>`

## 4. 入出力仕様

- 入力: なし
- 出力: HTML文字列（部分）。単独では完結したHTMLにならず、`header.ejs`とセットで使用する前提

## 5. 特記事項・留意点

- 動的な内容を持たないため、通常はレイアウト変更（コピーライト年表記の追加等）以外での改訂は想定しない。
