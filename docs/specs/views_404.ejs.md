## 1. 概要

| 項目 | 内容 |
|---|---|
| ファイルパス | `views/404.ejs` |
| 役割 | 404エラー画面（SCR-06）。存在しない記事ID・未定義URLへのアクセス時に表示する |
| 描画元ルート | `GET /posts/:id`（記事未存在時）, `POST /posts/:id/comments`（記事未存在時）, `POST /posts/:id/delete`（記事未存在時）, フォールバックルート（未定義URL全般）（いずれも`server.js`、いずれもHTTPステータス404） |

## 2. 位置づけ・依存関係

- `partials/header.ejs`, `partials/footer.ejs`をインクルード

## 3. 詳細仕様

### 3.1 受け取る変数

なし

### 3.2 描画ロジック

1. ヘッダーへ`pageTitle: 'ページが見つかりません'`を渡してインクルード
2. `<div class="not-found">`：見出し「404」、固定文言「お探しのページが見つかりませんでした。」、ホーム（`/`）へのリンク

## 4. 入出力仕様

- 入力: なし
- 出力: HTML全体（HTTPステータス404で返却。ステータス設定は呼び出し元の`server.js`側で`res.status(404).render('404')`として行う）

## 5. 特記事項・留意点

- 本テンプレート自体はHTTPステータスコードを設定しない。ステータスコードの付与は必ず呼び出し元（`res.status(404)`）で行う必要がある。
