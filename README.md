# JSON Blog

JSONファイルをデータストアとして利用する、シンプルなブログシステムです。データベースサーバーを立てずに、記事の投稿・閲覧、コメント、検索、カレンダー機能を利用できます。

## 主な機能

- **記事管理**: 記事の投稿（TinyMCEリッチテキストエディタ対応）・一覧表示・詳細表示・削除
- **リポスト機能**: 既存記事のリポスト（再共有）、フィード上でのリポスト日時順表示、リポスト件数表示（リポストの実行にはログインが必要）
- **カテゴリー機能**: カテゴリー一覧表示、カテゴリーごとの記事絞り込み
- **タグ機能**: タグ一覧表示、タグごとの記事絞り込み
- **コメント機能**: 各記事に対する読者とのコミュニケーション（コメント投稿・一覧表示）
- **検索機能**: タイトル・本文・カテゴリー・タグを対象としたキーワード検索
- **カレンダー機能**: 月別カレンダー表示、投稿がある日付から記事を絞り込み表示
- **ログイン機能**: 新規投稿画面の利用およびリポスト操作には固定ID・パスワードによるログインが必要（既定値: ID `admin` / パスワード `admin1234`。`lib/auth.js`で変更可能）

## 技術スタック

| レイヤー | 技術 |
|---|---|
| 実行環境 | Node.js |
| Webフレームワーク | Express |
| テンプレートエンジン | EJS |
| リッチテキストエディタ | TinyMCE |
| データストア | JSONファイル（`data/posts.json`, `data/comments.json`, `data/reposts.json`） |

## セットアップ

```bash
npm install
npm start
```

起動後、`http://localhost:3000` にアクセスしてください。ポートは環境変数 `PORT` で変更可能です。

開発時はファイル変更を自動反映する場合、以下を利用できます。

```bash
npm run dev
```

## ディレクトリ構成

```
blog/
├── server.js              エントリポイント・ルーティング定義
├── lib/
│   ├── db.js               JSONファイルの読み書き・データアクセス関数群
│   └── auth.js              固定ID・パスワードによるログイン判定、Cookieセッション
├── data/
│   ├── posts.json          記事データ
│   ├── comments.json       コメントデータ
│   └── reposts.json        リポストデータ
├── views/                   EJSテンプレート（画面）
├── public/css/style.css     共通スタイル
└── docs/                     設計ドキュメント一式
```

## データについて

記事・コメント・リポストはそれぞれ `data/posts.json` / `data/comments.json` / `data/reposts.json` に平文のJSONとして保存されます。テキストエディタで直接内容を確認・編集することも可能です（構文を崩さないようご注意ください）。
